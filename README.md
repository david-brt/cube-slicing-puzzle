# Cube Slicing Puzzle

An interactive 3×3×3 cube slicing puzzle. Cut the cube with one plane at a time,
rearrange the pieces between cuts, and try to reach 27 unit cubes in as few cuts as possible.

**Play it: https://david-brt.github.io/cube-slicing-puzzle/**

A single self-contained HTML file — no build step, no dependencies. The 3D view is a
hand-rolled isometric canvas renderer.
